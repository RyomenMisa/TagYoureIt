# TagYoureIt
Endpoint Detection and Response
====================================================
           TAG YOU'RE IT - by Misa
====================================================

[!] ОБЩАЯ ИНФОРМАЦИЯ
EDR работает в пространстве пользователя (Ring 3). 
В текущей версии нет драйверов для уровня ядра (Ring 0). 
Помните: системные антивирусы с доступом в Ring 0 всегда 
имеют приоритет и могут интерпретировать работу EDR как 
подозрительную активность.

[!] ПРИНЦИП РАБОТЫ
Система использует поведенческий анализ и методы 
инъекции кода в целевые процессы для мониторинга 
активности. Это позволяет отслеживать угрозы в реальном времени, 
а не просто сравнивать файлы по базе сигнатур. 
Будьте осторожны: агрессивные антивирусные решения 
могут принудительно завершить работу EDR.

[!] КОНФИГУРАЦИЯ И ПРАВИЛА
Вы можете самостоятельно задавать правила для изоляции 
или остановки нежелательных процессов через файл 'rules.txt'.
* Предупреждение: внесение некорректных правил в C++ ядро 
может привести к нестабильной работе системы. 
Если всё пойдет по пзде — ебться в коде C++ придется вам.
При расшифровке карантинной программы создается текстовый файл с препарированием здесь же.  

[!] СТРУКТУРА
* TagYoureIt.exe  — Консольное ядро (C++).
* TagYoureIt_EDR.exe — Графический интерфейс (Python) + ядро (C++).
* edr_core_activity.log — Содержание всех ваших логов.
